# SWI Interoperable Organization Workflow Template

**PROTOTYPE ONLY — NOT PRODUCTION AUTHORIZATION**

## Discipline

```
UNKNOWN ≠ FALSE
QUESTION ≠ DENY
REVIEW ≠ FAILURE
HOLD ≠ HALT
PASS ≠ UNIVERSAL AUTHORITY
HASH ≠ AUTHORITY ≠ TRUTH
```

## 14 stages

| # | Stage | Question |
|---|-------|----------|
| 01 | IDENTIFY | What workflow, actors and objective? |
| 02 | BOUNDARY | What is inside/outside? |
| 03 | CONTRACT | What obligations and conditions? |
| 04 | INPUT | What entered, from where, provenance? |
| 05 | ADMISSION | What evidence permits entry? |
| 06 | POLICY | Which rules apply? |
| 07 | CAPACITY | What capacity is evidenced? |
| 08 | COMPETITION | What independent providers exist? |
| 09 | ALTERNATIVES | What alternatives are evidenced? |
| 10 | SWITCHING | Can the workflow actually switch? |
| 11 | EXECUTION | What action and what authority? |
| 12 | EVIDENCE | What proves what happened? |
| 13 | REVIEW | What remains unresolved? |
| 14 | EXIT | How does the workflow stop/transfer/complete? |

STAGE EXISTS ≠ STAGE PASSED.

## Resolution states

`QUESTION_REQUIRED` · `EVIDENCE_REQUIRED` · `CONTEXT_REQUIRED` · `AUTHORITY_REQUIRED` · `REVIEW_REQUIRED` · `PASS` · `HALT` · `BLOCK`
